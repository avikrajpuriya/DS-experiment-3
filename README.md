# Experiment 3 – Measuring Central Tendency and Variability

This project is based on the Experiment 3 handout and the `urban_climate.csv` dataset.

## Files included

- `EXP3_Instructions.pdf` – experiment instructions.
- `urban_climate.csv` – dataset used by the programs.
- `mean median mode.py` – frequency, mean, median and mode.
- `variance.py` – sample variance.
- `standard deviation.py` – sample standard deviation.
- `iqv.py` – quartiles and interquartile range.
- `grouped_data_analysis.py` – statistical analysis grouped by city.
- `EXP3_Statistical_Analysis.ipynb` – notebook with code, activities and inferences.

## How to run

1. Extract this ZIP file.
2. Keep the CSV file and Python programs in the same folder.
3. Run a program from this folder, for example:

   `python "mean median mode.py"`

   `python variance.py`

   `python "standard deviation.py"`

   `python iqv.py`

   `python grouped_data_analysis.py`

## Important

Each Python program contains its own calculation functions. **No separate helper file is required.** The programs read `urban_climate.csv` by filename, so keep the CSV in the same folder and run the program from that folder.

The calculations for mean, median, mode, variance, standard deviation and IQR are written using loops and basic Python operations rather than ready-made statistical functions. Variance and standard deviation use the sample formula (`n - 1`).
